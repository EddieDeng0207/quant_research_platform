# P0.8 历史行业归属标准

## 目标

行业中性化必须使用决策时点有效的行业归属，禁止把当前行业标签直接回填历史。
正式口径采用申万一级行业，并同时保存供应商原始纳入、剔除区间和分类体系版本。

## 分类体系切换

- 2016-01-01 至 2021-12-12：`SW2014`；
- 2021-12-13 起：`SW2021`；
- SW2021 成员接口即使返回更早的 `in_date`，也不得用于切换日前的研究截面；
- SW2014 开放区间统一截断于 2021-12-12。

这样避免用后发布的分类体系重写早期行业暴露。供应商 `out_date` 按剔除生效日
处理，研究用闭区间的 `membership_end` 等于 `out_date - 1日`。

## 接入与断点

```bash
.venv/bin/qrp-data backfill-industry \
  --requests-per-minute 250 \
  --job-name p08_industry_membership_2016_20260814
```

接入先冻结 SW2014、SW2021 一级分类目录，再对每个行业指数请求全部历史成员。
每个“分类体系 × 行业指数”都是独立 checkpoint；原始 Parquet、行数、查询参数和
SHA-256 写入 lake manifest。

## 不可变产物

```bash
.venv/bin/qrp-data build-industry-pit \
  --run <completed_run> \
  --start 2016-01-01 \
  --end 2026-08-14
```

正式构建要求干净 Git 状态，并绑定 commit、依赖锁、运行清单、checkpoint 和全部
原始文件哈希。产物主键为 `membership_id`，同一股票的有效区间不得重叠。

核心门禁：

- 两套分类体系必须同时存在；
- 原始任务网格必须完整；
- 原始文件哈希、行数、dataset 必须匹配；
- `membership_start <= membership_end`；
- 同一股票任一日期最多一个一级行业；
- 请求区间首尾必须被产物覆盖；
- 分类体系必须严格按生效窗口裁剪。

## 并发与限流

市场数据和财务数据允许多个网络线程隐藏响应延迟，但线程共享同一个线程安全限流器。
在250次/分钟配置下，请求启动时间至少间隔0.24秒；线程数不会放大总调用额度。
