# 因子研究工程标准

## 分层而不是混类

平台把因子研究拆成三层，三层产物分别冻结，不能在同一个字段里混合：

1. **原始信号层**：基本面、分析师预期、另类数据和量价因子；
2. **量化选股层**：多个已通过单因子工程门禁的信号经过方向统一、标准化、正交化和合成后形成选股分数；
3. **组合与交易层**：仓位、行业/市值约束、换手、容量、成交限制和费用模型。

“量化选股因子”因此不是与基本面、量价并列的数据来源，而是派生层。原始因子仍可单独复现；合成模型必须记录输入因子 artifact、权重估计窗口和训练版本；组合规则不能反向写入因子值。

## 首批研究地图

| 原始因子族 | 子类 | 首批候选 | 频率与主要风险 |
|---|---|---|---|
| 基本面 | 估值 | SP、BP、EP、CFP | 周频决策、季度信息；重点防公告时间前视和修订回填 |
| 基本面 | 质量/成长 | ROE、毛利率、应计、营收/利润增长 | 需要一致的 TTM/单季口径和金融企业专用公式 |
| 量价 | 反转/动量 | rev20_skip1、12-1 动量 | 周频；必须使用因果复权收益并显式处理停牌 |
| 量价 | 风险/流动性 | 波动率、换手率、Amihud | 周频；不得把停牌日伪造成零收益或零成交冲击 |
| 量化选股 | 合成评分 | 等权、IC 加权、风险约束评分 | 只消费已冻结的原始因子 artifact，不直接读取未来收益 |

新增因子必须先注册 `FactorDefinition`。注册信息包括因子族、研究层、方向、公式、数据依赖、PIT 政策、缺失处理、适用公司范围和版本；fingerprint 进入内容寻址身份。

## 统一研究链路

```text
P0.5/P0.8 冻结数据
    -> PIT 因子输入 artifact（observations 与 forward_returns 物理隔离）
    -> P0.7 单因子评测（覆盖率、分布、IC、分组、暴露、换手）
    -> P0.6.3 可成交回测（涨跌停、停牌、容量、冲击、费用）
    -> 可验证报告（输入哈希、参数哈希、Git commit、依赖锁）
    -> 通过后才允许进入多因子合成候选池
```

工程门禁通过只表示数据、时间、统计与产物契约成立，不代表因子有投资价值。研究结论必须等净成本回测和稳健性检验完成后再给出。

## 研究域与因子适用性

P0.5 的 `research_eligible` 是全平台基础资格，不得被因子层覆盖。因子层额外保留：

- `universe_in_scope`：预先冻结的交易板块和必需分类范围；
- `factor_applicable`：公式是否适用于该公司类型；
- `evaluation_eligible = research_eligible & universe_in_scope & factor_applicable`；
- `scope_exclusion_reason`：每一行被排除的确定性原因。

研究域必须在读取 `forward_returns` 之前生成，规则和 SHA-256 进入 artifact。P0.7
同时对“适用域内有效因子覆盖率”和“适用域相对 P0.5 股票池的保留率”做
80% 硬门禁。这两个比率不可在看过 IC、收益或回测后调整。

当前提供两个冻结档位：

| 档位 | 范围 | 用途 |
|---|---|---|
| `cn_a_full` | 沪深主板、创业板、科创板、北交所 | 全 A 诊断口径；当前历史申万对科创板/北交所覆盖不足，不得冒充正式行业中性化域 |
| `cn_a_sw_l1_core` | 沪深主板+创业板，要求当日有效申万一级 | 当前可做正式行业/市值中性化的核心研究域 |

科创板和北交所不是永久排除；待补充具有历史生效区间的行业分类后，新建并版本化对应研究域，不回写旧 artifact。
`302132.SZ` 依据交易所公告和原板块身份显式归入创业板；`300114.SZ -> 302132.SZ` 的法律链连续，但基本面业务链依据 aliases 在重组生效日截断。其他未冻结的 `302` 代码仍失败关闭，不通过前缀泛化猜测板块。

## SP v1 冻结定义

首个基本面因子为 `sp_ttm`：

```text
SP(i,t) = PIT_TTM_营业收入(i,t) / 决策日总市值(i,t)
expected_direction = +1
decision_at = 周度最后交易日 16:00 Asia/Shanghai
execution_at = 下一交易日 09:30 Asia/Shanghai
```

### PIT TTM

每个组成报表都独立选择 `available_at <= decision_at` 且
`source_ingested_at <= research_as_of_at` 的最新无歧义版本。年报直接使用全年累计值；一季报、半年报、三季报使用：

```text
TTM = 本年累计 + 上年全年累计 - 上年同期累计
```

同一证券、报告期和 `available_at` 若有多个供应商版本，以 SP 实际使用的 `revenue` 字段判定经济歧义：收入不一致时失败关闭；收入一致时可合并为字段级等价版本，但必须保留全部 `version_id`、版本数，并使用较晚的公告/入库时钟作为保守审计值。这不代表整张利润表等价。

缺少任一组成项时置空，不用单季乘四、线性外推或零填充。收入非正、报告陈旧超过 550 日、公司类型不属于普通工商企业时也置空并写入诊断。550 日不是数据填补规则，只是防止多年未披露的旧报表继续参与排序。

### 公司与证券身份

v1 使用利润表 `revenue`（营业收入）且只适用于 `comp_type=1` 的普通工商企业。银行、保险、证券使用不同收入结构，后续必须各自定义公式，不能为了提高覆盖率强行套用普通企业 SP。

法律主体连续但业务不连续的代码变更，价格链可以连续，基本面链必须从配置中的 `effective_date` 重置。重置后的 TTM 不能拼入重组前的年报或同期报表。

### 时间、价格与未来标签

市值来自决策日 `daily_indicators.total_mv`，数据湖已统一为人民币元，不得再次乘以 10,000。因子输入保留财报 `announcement_at/available_at/source_ingested_at/research_as_of_at`；没有有效因子值的行可以没有财报事件时钟，但任何有限因子值都必须完整通过时间门禁。

基本面因子的周频决策从研究区间内第一个完整周开始，只要未来最长持有期标签完整即可；不继承量价因子的 120 日形成窗口预热。新股过滤仍严格保留，但上市时长使用 P0.5 `list_date` 和内容校验过的冻结交易日历计算，不得从研究起始日重新计数。交易日历身份、覆盖区间和哈希写入 artifact manifest。

未来收益单独保存为下一交易日开盘起算的因果复权开盘到开盘收益。因子形成函数不读取该文件。

## 产物与审计

`build-sales-to-price-inputs` 生成：

- `observations_sp_ttm.parquet`：可直接交给 P0.7 的周频因子面板；
- `ttm_revenue_diagnostics.parquet`：每个决策日、每个已披露证券的 TTM 组成、版本、状态和业务链重置标记；
- `forward_returns.parquet`：与因子物理隔离的 5/10/20/60 日结果标签；
- `manifest.json`：输入哈希、公式与参数 fingerprint、Git/依赖身份、质量读数和 guardrails。

正式 CLI 默认要求 clean Git；`--allow-dirty-code` 只能用于探索产物。正式发布前必须在已提交代码上重新生成，不能把工作区哈希冒充可回溯版本。
