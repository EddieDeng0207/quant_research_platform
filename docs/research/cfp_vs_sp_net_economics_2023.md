# CFP 与 SP 净经济性对照（2023）

## 结论

在相同的 2023 年 P0.5 可交易域、1,000 万元初始资金、公司行为、费用与四执行情景下，`cfp_ttm` 的长期 Rank IC 高于 `sp_ttm`，但基础执行净收益略低：12.24% 对 12.57%。主要差异不是毛收益，而是 CFP 的成交额和成本更高。

这次对照给出一个重要的研究约束：统计排序能力、组合换手和净经济性必须串联评估；不能按 IC 排名直接选择实盘因子。

代理毛收益口径为：

```text
proxy_gross_return = net_return + (total_fees + total_slippage_cost) / initial_nav
```

它用于会计分解，不是一套独立的零成本可成交账本。

CFP 单笔成交额更大，因此每元成交的佣金效率优于 SP；但全年成交额更高，最终总成本仍高 0.24pp。两个因子都暴露了“约 800–900 只股票的宽组合在 1,000 万元资金下订单过碎”的共同结构问题。

严格容量下界两者均为零，因为任一目标证券缺失必要容量输入就把当日严格容量归零。条件诊断不能替代该下界：

| 正容量日条件诊断 | CFP | SP |
|---|---:|---:|
| 基础情景 P10 | 3,449 万 | 2,614 万 |
| 保守情景 P10 | 859 万 | 651 万 |
| 基础情景中位数 | 6,178 万 | 6,711 万 |
| 保守情景中位数 | 1,539 万 | 1,672 万 |

CFP 的保守条件 P10 低于本次 1,000 万元账户，所以不能宣称 1,000 万元在 90% 正容量日均安全。

## 数据完整性发现

CFP 首次构建发现 `cashflow_vip` 在请求 9,000 行时会静默只返回 6,400 行。旧分页器把“返回少于请求 limit”误当作末页，使 23 个季度被截断，CFP 覆盖率中位/最低仅为 82.22%/54.21%。

修复后，VIP 分页按实际返回行数推进 offset，并请求到明确空页才结束；现金流 PIT 由 257,495 行恢复到 322,711 行，CFP 输入覆盖率恢复到 91.32%/88.32%。P0.7 的 80% 门禁没有降低。

## 当前研究判断

1. CFP 与 SP 都能在 2023 年穿过成本层，低换手基本面方向得到第二个独立样本支持。
2. CFP 的 IC 优势没有转化为净收益优势，说明组合变化与执行成本必须进入因子选择目标。
3. 两者约 12% 的单年净收益高度接近，可能包含共同的价值暴露；进入多因子前应先计算截面相关性、收益相关性和增量 IC。
4. 下一个优先级是组合构建：Top-N、缓冲区、累积偏离触发以及行业/市值约束下的成本优化，而不是继续扩张到更多高度相关的估值因子。

## 边界

- 本对照仅使用 2023 年执行样本，不是跨状态实盘承诺。
- P0.7 使用中性化因子评估，但 P0.6.3 是可交易多头组合，仍需读取实际组合暴露与基准差异。
- 日线执行不能还原集合竞价排队或盘中开板；冲击参数在真实成交回报接入前仍是冻结假设。
- `commission_aware_open` 的全不交易结果是极端小额订单过滤情景，不代表因子没有经济性。
