# SP 与 rev20_skip1 净经济性对照（2023）

## 结论

在完全相同的 2023 年 P0.5 可交易域、1,000 万元初始资金、公司行为、交易费用和四执行情景下，低换手基本面因子 `sp_ttm` 的净经济性明显优于 `rev20_skip1`。这支持“反转因子的成本吞噬主要来自其高换手，不是平台上所有因子的共同宿命”。

但 SP 仍未解决小额订单和容量缺失：基础情景 99.70% 的已成交订单命中 5 元最低佣金，而严格容量在大量日期为零。因此当前结论是“SP 值得进入组合构建优化”，不是“可直接实盘”。

## 同口径经济性

| 指标 | SP | rev20_skip1 |
|---|---:|---:|
| 基础执行净收益 | 12.57% | 2.41% |
| 代理毛收益（净损益 + 已支付费用/滑点） | 14.73% | 11.44% |
| 费用 + 滑点/初始资金 | 2.16% | 9.03% |
| 成本占代理毛利 | 14.68% | 78.95% |
| 成交额/平均 NAV | 7.21x | 37.99x |
| 保守执行净收益 | 12.15% | 0.06% |
| 延迟一交易日净收益 | 10.09% | -1.64% |
| 最大回撤（基础执行） | -10.05% | -14.81% |

“代理毛收益”是为了与上一轮 rev20 报告保持同口径的会计分解：

```text
proxy_gross_return = net_return + (total_fees + total_slippage_cost) / initial_nav
```

它不是一套独立零成本账本；费用还会通过现金约束轻微影响后续持仓，因此不得把该值当成可成交收益。

## 成本结构

| 基础情景 | SP | rev20_skip1 |
|---|---:|---:|
| 费用 | 95,278.68 | 378,813.48 |
| 滑点与冲击 | 120,921.55 | 524,253.61 |
| 已成交订单中位数 | 1,998 | 10,349 |
| 已成交订单 P10 | 393 | 2,996 |
| 最低佣金命中率 | 99.70% | 99.98% |
| 实际综合佣金率 | 8.31bp | 5.38bp |
| 全费用率 | 12.03bp | 9.53bp |

SP 的单笔交易更小，所以每元成交额的佣金效率反而更差；它的总成本较低主要来自全年成交额约为平均 NAV 的 7.21 倍，而不是单笔执行更便宜。

`commission_aware_open` 对 SP 抑制 43,496 笔例行订单，计划金额 4.65 亿元，最大单笔目标差异仅 0.115%，最终整个账户不交易。这说明“低于 16,666.67 元全部不调仓”对 1,000 万元、约 870 只股票的组合过于粗糙，后续应优化组合集中度或引入累积偏离触发，不应删除最低佣金。

## 容量与不确定性

SP 基础情景的 228 个容量观测日中，160 日因任一目标证券必要容量输入缺失而归零；正容量日仅占 29.82%。所以严格无条件容量下界仍为 0，不允许报告一个伪精确的“安全 AUM”。

| SP 容量诊断 | 基础执行 | 保守执行 |
|---|---:|---:|
| 正容量日条件 P10 | 2,614 万 | 651 万 |
| 正容量日条件中位数 | 6,711 万 | 1,672 万 |

保守条件 P10 低于本次 1,000 万元账户，因此这一规模不能被称为“90% 正容量日都安全”。若只按当前组合构造与保守执行诊断，651 万元可作为条件上限参考，但它不能覆盖严格零容量日风险。

长停牌估值不确定性不改变结论：SP 基础情景最大 NAV 上下界宽度 0.1799pp，全情景最坏 0.1925pp，显著低于冻结的 2pp 容忍度。

## 当前研究判断

1. SP 在 2023 的排序能力能穿过成本层，不是只在 IC/分层表上显著。
2. 与 rev20_skip1 相比，成本占代理毛利从 78.95% 降至 14.68%，证明低换手方向值得继续。
3. 单年 2023 的净收益不能代替样本外验证；P0.7 已显示 SP 在 2019、2020、2025 走弱，2026 不完整样本为负。
4. 下一个优先级不是新增更复杂因子，而是建立组合构建层：控制持股数、设置累积偏离触发、在行业/市值中性约束下降低小额订单，并将严格零容量日作为追踪误差风险显式上报。

## 边界

- 回测使用日线可证明的保守执行，不还原集合竞价排队或盘中开板。
- 滑点和冲击系数在导入真实券商成交回报前仍是冻结研究假设。
- `commission_aware_open` 是最低交易金额极端情景，完全不交易不代表 SP 没有经济性。
- 本报告是因子与执行研究结论，不是实盘收益承诺。
