# 数据源决策记录

## 2026-08-14：首批接入

### Tushare Pro

用途：A 股证券主数据、交易日历、未复权日线、独立复权因子、每日估值/市值、现金分红/送转版本、三张财务报表和财务指标。

原因：字段结构稳定，包含退市状态、公告日期、实际公告日期和复权因子，适合搭建周频横截面研究底座。

风险：权限依赖积分；证券主数据的历史截面仍需平台自行归档；供应商字段不等同于交易时点可得性，必须在 curated 层执行滞后和版本规则。分红原始层同时保留预案、股东大会与实施记录；只有实施版本可进入回测账本，且必须使用实施公告日建立知识时间。

### AKShare

用途：免密启动、单标的日线和当前证券列表、与主来源交叉检查。

风险：数据来自聚合网页接口，接口与字段可能变化；当前列表存在幸存者偏差；供应商文档已列出部分复权异常案例。因此不把 AKShare 调整价作为唯一事实源。

### FRED/ALFRED

用途：宏观数据与数据修订历史。研究应优先保留 `realtime_start` 和 `realtime_end`，避免用今天修订后的宏观历史解释过去的策略决策。

### 暂缓接入

- Yahoo Finance：适合探索，不作为 A 股核心主数据。
- BaoStock：后续作为第二个免费 A 股校验源。
- SEC EDGAR：在扩展美股基本面时接入；其 XBRL/提交历史 API 无需密钥，但必须遵守自动访问要求。
- 分析师预期：等待能提供历史快照、预测期、机构、分析师和更新时间字段的授权源。
- 另类数据：先定义每个数据集的实体映射、事件时间、知识时间、修订和许可条款，再实现适配器。
