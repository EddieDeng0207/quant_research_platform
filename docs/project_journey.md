# 项目演进与关键决策

## 1. 研究目标

项目最初目标是建设一套可交付、可复现的中低频量化研究平台，覆盖数据接入、特征与因子构建、回测、成本、容量和报告生成。研究频率以周频决策为主，因子方向包括基本面、分析师预期、另类数据和量价信号。

选择中低频而非中高频的原因是：公开或低成本数据难以提供稳定的逐笔/盘口历史、完整撮合状态和可靠的复权校准。即使中高频回测表现很好，也可能只是数据精度无法支持的伪结果。

## 2. 建设原则

平台不是先追求一个高收益策略，再为结果补解释，而是按以下顺序降低研究不确定性：

1. 冻结原始数据和供应商请求；
2. 解决证券身份、复权和数据可得时间；
3. 建立当日研究资格与下一日执行约束；
4. 建立因子统计评测和真实组合暴露门禁；
5. 将目标权重送入统一成交、成本和容量回测；
6. 由不可变产物自动生成报告；
7. 最后才比较因子的净经济性。

## 3. 阶段演进

| 阶段 | 当时的主要风险 | 完成的处理 | 对后续研究的意义 |
|---|---|---|---|
| P0 数据接入 | 供应商分页、速率限制、数据覆盖不透明 | 400 次/分钟全局限流、接口级最大页长、断点续传、不可变 raw 与请求 manifest | 同一数据请求可审计、可续跑、不会静默截断 |
| P0.G0 版本治理 | 代码哈希指向随时被覆盖的工作区 | Git 分支/PR、clean-tree 晋级、依赖锁、release manifest | artifact 能绑定到可恢复的代码状态 |
| 复权与隔离 | 动态前复权和未来公司行为污染历史 | 保存未复权价与独立复权因子；因果收益和展示价格分模态 | 避免用未来锚点改变历史因子收益 |
| P0.5 可交易性 | 停牌、涨跌停、ST、退市和制度切换被忽略 | 方向性成交约束、官方边界、历史证券状态、缺失失败关闭 | 因子层不借用执行日信息，执行层不假设一定成交 |
| P0.6.1–P0.6.3 | 换手、最低佣金、冲击和容量被低估 | T+1、部分成交、平方根冲击、最低佣金、公司行为、长停估值上下界 | 从“纸面组合”进入可交易净收益 |
| P0.8 PIT | 财报修订、历史行业和代码变更造成前视或错配 | 公告/实际公告双时间、修订保留、申万历史区间、统一 instrument_id | 基本面因子只读取决策时已知版本 |
| P0.7 因子评测 | 线性中性化通过但 Top 组合仍有行业/市值押注 | Top/Bottom 真实组合暴露、噪声感知行业阈值、HAC 与多持有期标签 | 统计显著性与实际持仓暴露同时受控 |
| 首个量价实验 | 20 日反转可能被最近一日价差跳动污染 | 同时评测 rev20 与 rev20_skip1，显式处理停牌观测和上市时间 | 跳过最近一日成为正式反转口径 |
| 首个基本面实验 | 低换手因子能否穿过执行成本未知 | 构建 PIT TTM 营收市值比 SP，并贯通 P0.7→P0.6.3 | 验证成本吞噬不是所有因子的共同命运 |

模块编号描述职责边界，不等同于时间顺序。例如 P0.8 的 PIT 数据能力必须先准备好，P0.7 才能正式研究基本面因子。

## 4. 关键设计决策

### 4.1 AKShare 的定位

AKShare 用作免密启动和横向核验，不单独承担生产级历史主数据。正式 A 股历史数据以 Tushare 不可变快照为主，重要制度与证券身份事件再使用交易所或巨潮公告复核。

### 4.2 复权价格不直接作为主事实

平台保存未复权价格、独立复权因子和公司行为，再按研究截止时点构建派生序列。因子窗口使用因果日收益连乘，不用会随查询终点变化的动态前复权价格相除。

### 4.3 研究资格与实际成交分离

因子面板只使用决策日能够观察的 `research_eligible`，避免提前知道下一交易日是否停牌或封板。执行日无法成交由 P0.6.3 的订单与成交状态处理，未成交会进入组合路径，而不是从历史目标中消失。

### 4.4 中性化不只检查回归一阶条件

WLS 残差与行业、市值回归项正交只能证明数值求解正确。平台额外检查 Top/Bottom 组合的行业主动权重和市值偏离，并使用随分组规模变化的噪声感知阈值，避免小股票池被固定阈值结构性误杀。

### 4.5 容量采用失败关闭下界

如果任一目标证券缺少成交额、波动率或自由流通盘等必要容量输入，当日严格容量记为零。正容量日 P10 和中位数只作为条件诊断，不能替代严格容量或隐藏缺失风险。

### 4.6 长停牌估值报告上下界

超过冻结陈旧期的持仓同时报告末价上界和减记为零的保守下界。区间缺失或宽度超过容忍度仍阻止晋级。这比使用未经校准的复牌重定价启发式更诚实，也让不确定性可以量化。

## 5. 首轮端到端发现

rev20_skip1 的 2023 年代理毛收益为 11.44%，但费用与滑点消耗初始资金的 9.03%，净收益只剩 2.41%。SP 的代理毛收益为 14.73%，成本为 2.16%，净收益为 12.57%。

这个实验没有证明 SP 可以直接实盘，但回答了一个更基础的问题：平台并非系统性地把所有因子成本估高到不可交易，高换手是反转因子的特定弱点。下一步应优化组合构建，而不是立即增加更复杂的估值模型。

## 6. 当前路线

### 下一阶段：组合构建

- 比较 Top 200 / 300 / 400 持股数量；
- 加入行业配额和市值暴露约束；
- 使用 no-trade buffer 或累积偏离触发，减少小额周频调仓；
- 对 500 万、1,000 万和 2,000 万元做资金敏感性；
- 同时报告跟踪误差、成本、容量和未成交路径。

### 后续因子研究

- 基本面：CFP、EP、BP、质量与盈利能力；
- 量价：中期动量、短期反转、波动率、换手和流动性；
- 量化选股：因子合成、行业/市值中性化、相关性与拥挤控制；
- 数据条件成熟后：分析师预期和可验证的另类数据。

## 7. 如何审计这段过程

- 工程规则：查看 `docs/` 下各阶段标准；
- 正式结论：查看 `docs/research/README.md` 标记为“当前正式”的报告；
- 版本身份：查看 Git tags、PR 历史和 `releases/*/manifest.json`；
- 实现细节：从 `src/qrp/` 对应模块进入；
- 边界测试：从 `tests/` 中与模块同名的测试文件进入。
